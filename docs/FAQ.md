# FAQ — TheQuantGPT Cursor Lab

1. **Do I need to code?** No manual coding; you prompt and review. Comfort reading metrics and folders helps.

2. **Where does my data live?** On your server. Not sent to our API except workflow instructions (no bulk OHLCV upload).

3. **Do you see my data?** No by default.

4. **What do I pay separately?** Cursor, cloud server, LLM API usage.

5. **What is the trial?** 7-day free trial with full MCP access. No card required if we agree otherwise; after trial, paid setup + monthly retainer.

6. **What if I cancel?** Keep server, data, code, artifacts; lose MCP access and updates.

7. **Live trading?** No — research and backtesting only.

8. **Which markets?** Any asset class with OHLCV data — crypto, equities, FX, bonds, metals, commodities, etc. A fresh clone includes Binance daily spot and futures OHLCV under `data/binance/`. Add other local files or use yfinance when needed.

9. **How long is setup?** Typically 1–2 working sessions after prerequisites.

10. **Support?** Async support + onboarding calls per package.

11. **Investment advice?** No. Research tooling only; no performance guarantees.
